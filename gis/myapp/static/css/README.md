# CSS structure

- `layout/`: CSS chung cho layout goc.
- `pages/`, `news/`, `catalog/`, `locations/`, `shop/`, `account/`: CSS tach rieng theo template nghiep vu.
- `admin_panel/`: CSS rieng cho tung man hinh quan tri.
- `style.css`, `pharma-refresh.css`, `ui-enhancements.css`, `support-widget.css`: bo CSS tong quan da ton tai tu truoc.
